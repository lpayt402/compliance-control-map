# SOC 2 framework pack

This pack contains 61 concise, independently authored readiness summaries for the 2017 AICPA Trust Services Criteria with the revised 2022 points of focus.

It intentionally does not reproduce official criterion text, COSO principles, points of focus, logos, or licensed publications. `summary` describes the intended outcome in original language; `guidance` contains clearly labeled illustrative practices. Consult the current AICPA material and your CPA for authoritative interpretation.

The pack is immutable by `slug`, `version`, and canonical content hash. Corrected or revised content should ship as a new version rather than silently changing an imported catalog.
